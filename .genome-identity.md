# ClearCvLovable

- **Scopo**: Wrapper di deployment legacy per l'app ClearCV generata con Lovable, pubblicata su clearcvapp.com; ora neutralizzato in favore di ClearCv.
- **Stack**: Cloudflare Workers (worker.js, wrangler.toml), Lovable submodule React, script Node (instant-indexing, sitemap).
- **Entry point**: `worker.js` (Worker con routing SPA + patches), `wrangler.toml`, `clear-cv-integration/` (submodule Lovable READ-ONLY), `patches/` (fix urgenti), `scripts/instant-indexing.mjs`.
- **Comandi**: `wrangler dev` (locale su 8787), `wrangler deploy`, `npm run build --prefix clear-cv-integration` (build Lovable), `bash purge-cache.sh`.
- **Maturita'**: legacy/deprecato. Worker neutralizzato (nome cambiato in `clearcv-app-legacy`, route production rimosse); ClearCv e' l'unico sorgente di deploy per clearcvapp.com. Non deployare da questo repo.
- **Gotcha**:
  - `clear-cv-integration/` e' un submodule READ-ONLY: non modificare, non committare, non merge/rebase.
  - Fix urgenti vanno in `patches/` o `worker.js`, mai nel submodule.
  - Aggiornamenti Lovable ~1x/mese via `git pull` nel submodule + rebuild.
- **Deploy**: NON in produzione (worker legacy); il deploy reale e' gestito da ClearCv.
- **Segreti**: KV namespace IDs in `wrangler.toml` (CV_STORAGE, USER_SESSIONS); nessuna API key nel repo.
- **Dipendenze esterne**: Cloudflare Workers/KV, Lovable (sorgente esterno), Google APIs (instant-indexing postbuild).
